■ 2. 記録が出力されなくなった原因
--------------------------------------------------------------
元サイト（NISHI 形式の結果ページ）に「記録表示：1/100 ⇔ 1/1000」の
切替が追加された際、結果データ（result/～.json）の記録の項目名が
次のように変更されていました。

  旧仕様： "Kiroku"     : "10.59<br/>+1.4"
  新仕様： "Kiroku100"  : "10.59<br/>+1.4"    （1/100 表示）
           "Kiroku1000" : "10.584<br/>+1.4"   （1/1000 表示）

これまでのプログラムは "Kiroku" という項目名で記録と風速を探していたため、
新仕様のページではトラック種目の「記録」と「組の風速」が空欄になっていました。
（走幅跳などのフィールド種目は現在も "Kiroku" のままのため、正常に出力されていました）

今回の修正では、ご要望どおり 1/100 表示の記録（Kiroku100）を取得しています。


■ 3. 設置手順
--------------------------------------------------------------
※ 作業前に、サーバ上の現在のファイルを必ずバックアップしてください。

(1) 上段（NISHI の「GO!!」 → nishi.php）
    納品の nishi.php を、サーバの test フォルダにそのままアップロード（上書き）

(2) 下段（【info-ch用 ソースコード】の「GO!!」 → nishi_x-day.php）
    納品の nishi_x-day.php を、サーバの test フォルダにそのままアップロード（上書き）

(3) 2.php
    お使いの 2.php を、納品の 2.php に置き換えてください。

アップロード時のご注意
  ・FTP ソフトは「バイナリ」転送を推奨します。
  ・nishi.php は UTF-8、nishi_x-day.php と 2.php は従来どおり Shift_JIS で保存しています。
    エディタで開いて保存し直す場合は、文字コードを変更しないでください。
  ・アップロード後、表示が変わらない場合はブラウザの再読み込み（F5）をお試しください。


■ 4. nishi.php（上段）の出力仕様（エクセルsample.xlsx と同じ16列）
--------------------------------------------------------------
 日付         競技日                                    例）20260731
 大会名       大会名（Taikai.json）                     例）令和８年度全国高等学校総合体育大会
 種目         100M / 110MH / 4×100MR / 走り高跳び /     例）100M
              砲丸投げ / 八種競技 など
 風速         トラック：組の風速                        例）-1.6
              走幅跳・三段跳：選手ごとの風速（＋記号なし）
 レース状況   予選 / 準決勝 / 決勝 / ﾀｲﾑﾚｰｽ             例）予選
              種別がある大会は【】で付加                例）ﾀｲﾑﾚｰｽ【中学】
 組           複数の組がある場合のみ組番号              例）1
              （1組だけの場合・フィールド種目は空欄）
 順位         順位                                      例）1
 記録         1/100 表示。「:」「m」は「.」に変換        例）11.83 / 1.57.54 / 6.85
 氏名         姓と名の間は半角スペース                  例）鈴木 郁
 氏名カナ     空欄
 学年         氏名のカッコ内の学年                      例）3
 所属1        学校・クラブ名（リレーはチーム名）        例）東日大昌平
 所属2        都道府県・地区（リレーは空欄）            例）福島
 性別         男子 / 女子 / 男女混合                    例）男子
 表示/非表示  空欄
 備考         空欄

その他の仕様
  ・記録のない選手は、記録欄に DNS / DNF / DQ / NM を出力します（順位は空欄）。
  ・結果が未入力の組（スタートリスト）は出力しません。
  ・400m 以下の種目（100M～400M・ハードル・4×100MR）で1分を超える記録は
    秒に換算します（例：1.01.90 → 61.90）。
    ※ nishi_x-day.php（下段）・2.php も同じ換算を行います。
  ・混成競技（八種競技・七種競技・四種競技など）は総合得点を出力します
    （日付は混成競技の最終日）。混成の各種目（八種競技100m など）は出力しません。
    nishi.php 冒頭の NISHI_KONSEI_EVENTS を true にすると、各種目も出力されます。
  ・パラ種目は従来どおり出力しません。
  ・並び順は、大会の種目一覧の順（男子 → 女子、種目順）→ ラウンド順です。
  ・氏名・所属の半角カナ、英数字の半角化は、エクセルsample に合わせています。
  ・URL は TimeTable.html のほか、shtml フォルダの URL や各結果ページの URL を
    入れても動作します。
  ・結果ファイルは並列で取得するため、インターハイ規模の大会でも数秒で表示されます。
  ・URL の誤りなどで取得できない場合は、表の上に赤字でメッセージを表示します。

■ 6. 補足
--------------------------------------------------------------
  ・nishi.php は PHP 5.4 以降（7.x / 8.x）で動作するように作成しています。
  ・元サイトの仕様が今後再度変更された場合は、別途調査・修正が必要になる
    可能性があります。
  ・ご参考：jaaf.php には、PHP 8.2 以降でエラーになる書き方
    （mb_convert_kana の 'kvrns' 指定）が含まれています。
    サーバの PHP バージョンを更新される際はご注意ください。
