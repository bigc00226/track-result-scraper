■ 2. 記録が出力されなくなった原因
--------------------------------------------------------------
元サイト（NISHI 形式の結果ページ）に「記録表示：1/100 ⇔ 1/1000」の
切替が追加された際、結果データ（result/～.json）の記録の項目名が
次のように変更されていました。

  旧仕様： "Kiroku"     : "10.59<br/>+1.4"
  新仕様： "Kiroku100"  : "10.59<br/>+1.4"    （1/100 表示）
           "Kiroku1000" : "10.584<br/>+1.4"   （1/1000 表示）

これまでのプログラムは "Kiroku" という項目名で記録と風速を探していたため、
新仕様のページではトラック種目の「記録」と「組の風速」が空欄になっていました。
（走幅跳などのフィールド種目は現在も "Kiroku" のままのため、正常に出力されていました）

今回の修正では、ご要望どおり 1/100 表示の記録（Kiroku100）を取得しています。


■ 3. 設置手順
--------------------------------------------------------------
※ 作業前に、サーバ上の現在のファイルを必ずバックアップしてください。

(1) 上段（NISHI の「GO!!」 → nishi.php）
    納品の nishi.php を、サーバの test フォルダにそのままアップロード（上書き）

(2) 下段（【info-ch用 ソースコード】の「GO!!」 → nishi_x-day.php）
    納品の nishi_x-day.php を、サーバの test フォルダにそのままアップロード（上書き）

(3) 2.php
    お使いの 2.php を、納品の 2.php に置き換えてください。

アップロード時のご注意
  ・FTP ソフトは「バイナリ」転送を推奨します。
  ・nishi.php は UTF-8、nishi_x-day.php と 2.php は従来どおり Shift_JIS で保存しています。
    エディタで開いて保存し直す場合は、文字コードを変更しないでください。
  ・アップロード後、表示が変わらない場合はブラウザの再読み込み（F5）をお試しください。

■ 7. 10月4日の更新内容（nishi_x-day.php・2.php）
--------------------------------------------------------------
 症状
  ・一部の大会で、上段（nishi.php）は出力されるのに、
    【info-ch用 ソースコード】（nishi_x-day.php）では何も出力されない。
    例：2026年度 第８回仙台大学競技会
        https://newsflash.sendaiutf.org/nans21v/shtml/TimeTable.html

 原因
  ・この大会のサーバは、ブラウザ名（User-Agent）の付いていない読み込みを
    拒否（403 Forbidden）します。
    nishi_x-day.php・2.php は、ブラウザ名を付けずに大会のデータを読み込んで
    いたため、データを取得できず、何も出力されませんでした。
    （nishi.php はブラウザ名を付けて読み込んでいるため、出力されていました。
      これまでの大会のサーバは、ブラウザ名がなくても読み込めていました）

 修正
  ・大会のデータを読み込むときに、ブラウザ名を付けるようにしました
    （プログラムの上の方に 1行追加。それ以外は変更していません）。

 確認
  ・仙台大学競技会：38種目が出力されること、上段（nishi.php）の全選手 400人が
    含まれていることを確認しました。
  ・松戸市選手権・愛知県私学祭：出力が修正前と 1文字も変わらないことを確認しました。
  ・お客様のサーバで動いている nishi_x-day.php が、前回の納品物と同じであることも
    確認済みです（そのまま上書きできます）。

 設置
  ・nishi_x-day.php を、サーバの test フォルダにアップロード（上書き）してください。
    2.php をお使いの場合は、2.php も同じように置き換えてください。
  ・文字コードは従来どおり Shift_JIS です。エディタで開いて保存し直す場合は、
    文字コードを変更しないでください。


■ 8. 10月10日の更新内容（nishi_x-day.php・2.php）
--------------------------------------------------------------
 症状
  ・【info-ch用 ソースコード】（nishi_x-day.php）で、種目名は出力されるのに、
    各種目の中身（氏名・所属など）が何も出力されない。
    例：第56回道南秋季陸上競技大会（10月10日～11日）
        https://ftpx.donan-rikkyo.jp/2026/festa/nans21v/shtml/TimeTable.html?_gl=1*rk7ocz*…
    （上段の nishi.php と【タイムテーブル】は、同じ URL で正常に出力されていました）
  ・2.php では、同じ URL で、どの種目も「男女混合」とだけ表示され、種目名・氏名・
    所属が出力されませんでした（2.php は種目名も各種目のデータから取得しているため）。

 原因
  ・入力された URL の最後に「?_gl=1*…」が付いていました。
    これは、Google アナリティクスを使っているサイトのリンクから大会ページを
    開いたときに、ブラウザのアドレスに自動で付く文字です。
  ・nishi_x-day.php・2.php は、入力された URL から「TimeTable.html」を除いた残りを
    大会のフォルダとして、各種目のデータ（result/～.json）の URL を作っていました。
    「?_gl=…」が残ったまま URL を作っていたため、各種目のデータをすべて読み込めず
    （大会のサーバが 403 Forbidden を返します）、種目名（TimeTable.json から取得）
    だけが出力されていました（2.php は上のとおり「男女混合」だけ）。
  ・URL の後ろに空白が 1文字付いている場合も、同じ症状になっていました。
  ・上段（nishi.php）と【タイムテーブル】（nishi_timetable.php）は、URL の
    「?」「#」から後ろと前後の空白を取り除いてから使っているため、正常に出力
    されていました。

 修正（nishi_x-day.php・2.php）
  ・URL の「?」「#」から後ろと前後の空白を取り除いてから、大会のフォルダを
    求めるようにしました。
  ・上段（nishi.php）と同じく、shtml フォルダの URL（…/shtml/）、各結果ページの
    URL、TimeTable.html の大文字・小文字違いなどを入れても動作するようにしました。

 あわせて修正した点（調査の中で見つかった、以前からの不具合です）
  (1) リレーのチーム名（nishi_x-day.php）
      リレーはチーム名ではなく所属の略称が出力されていたため、同じ学校の
      A チーム・B チームが同じ表示になっていました。
        例：「函大有斗高A」「函大有斗高B」が、どちらも「函大有斗高(北海道)」
      大会のページと同じチーム名（例：函大有斗高A(北海道)）を出力します。
      チーム名が入っていない棄権（DNS）のチームは、これまでどおり所属名です。
  (2) A決勝・B決勝の見出し（nishi_x-day.php・2.php）
      「A決勝」「B決勝」に分かれた決勝で、見出しが「組」とだけ表示され、
      先に出る B決勝の 1位が、種目の 1位のように見えていました。
        例：「決勝【一般】 組 1.1」→「決勝【一般】 B決勝 1.1」
      見出しに「A決勝」「B決勝」と表示します。
  (3) 同じ名前の種目が 2つある大会（nishi_x-day.php）
      例：第８回仙台大学競技会の「男子 110mH 決勝」「男子 砲丸投 決勝」などが 2つずつ。
      2つ目の種目をクリックしても開かず、選手が見られませんでした（開閉に使う
      id が 1つ目と同じだったため）。2つ目以降の id の後ろに番号（_2 など）を
      付けて、すべての種目が開くようにしました。表示される文字は変わりません。
  (4) 小学生の 80m・テニスボール投・ジャベボール投（2.php）
      2.php では、これらの種目のリンクが途中で切れて開けず、選手が表示されません
      でした（道南秋季では 15種目・129人）。開けるように直しました。
  (5) 各種目のデータの読み込み（nishi_x-day.php）
      ・同じデータを 2回ずつ読み込んでいたのを 1回にしました（大会のサーバへの
        アクセスが半分になり、表示も速くなります）。
      ・読み込みに失敗したとき・途中で切れていたとき・エラーのページが返って
        きたときは、1回だけ読み直します（読み直す前に 0.5秒待つのは 10回まで
        です。大会のサーバが止まっているときも、長く待たずに終わります）。
      ・それでも読み込めなかった種目があるときや、URL が正しくないときは、
        灰色の四角（コピー）の下に、黄色い枠でお知らせを表示します。
        お知らせはコピーされる範囲の外に表示しますので、貼り付ける内容には
        入りません。

 確認（4大会のデータで確認）
  ・道南秋季陸上（今回の大会）：「?_gl=…」付きの URL で、全種目・全選手
    （155種目・1,634行。10月10日17時時点のデータ）が出力されることを、
    大会のデータと 1人ずつ照合して確認しました。
    ※ 組分け前の決勝（小学生の100m決勝 8種目）は、大会のページでもまだ選手が
      入っていないため、種目名だけになります（組分け後に出力されます）。
  ・第８回仙台大学競技会・千葉県高校新人・埼玉県高校新人でも同じく、全種目・
    全選手が出力されることを確認しました。
  ・次の URL で、出力が「…/shtml/TimeTable.html」の場合と 1文字も変わらない
    ことを確認しました（nishi_x-day.php・2.php とも）。
      …/shtml/TimeTable.html?_gl=1*…（今回の URL）
      …/shtml/TimeTable.html#kumi_1　　…/shtml/TimeTable.html?20261010#top
      前後に空白が付いた URL　　…/shtml/TimeTable.json
      …/shtml/　　…/shtml（最後の / なし）
  ・nishi_x-day.php の出力で、修正前と変わるのは次の行だけです。
    それ以外は 1文字も変わりません。
      リレーの行（道南秋季 41行・千葉 1行・埼玉 2行）
      A決勝・B決勝の見出し（道南秋季 6行）
      仙台大学競技会の 2つ目の種目の id（4種目）
  ・大会のサーバが一時的にエラーを返す状態・エラーのページを返す状態・
    途中で切れたデータを返す状態を作って試し、読み直しによって全選手が出力

  ・2.php：今回の大会の全 155種目を 1つずつ開いて、全選手（1,634人）が表示

 設置
  ・nishi_x-day.php を、サーバの test フォルダにアップロード（上書き）してください。
