■ 1. 納品ファイル
--------------------------------------------------------------
 pdf_startlist.php      スタートリストの出力画面
                        （info-ch 用の HTML。一番上の灰色の四角でコピー）
 pdf_result.php         結果の出力画面（1.php と同じ 16列の一覧表）

                        pdfcore.js / startlist.js / startlist_render.js /
                        result.js / result_render.js / pdf_page.js

                        （トップページと同じ Shift_JIS で保存しています）


■ 2. 設置手順
--------------------------------------------------------------
(1) pdf_startlist.php と pdf_result.php を、サーバの test フォルダに
    アップロードしてください。

(2) pdf_js フォルダを、フォルダごと test フォルダにアップロードしてください。
    設置後は次のようになります。
      test/pdf_startlist.php
      test/pdf_result.php
      test/pdf_js/pdfcore.js（ほか 5ファイル）

(3) トップページ（tournament_result_top.php）に「PDF」欄を追加します。
    ・tournament_result_top.php をお送りいただければ、こちらで追加して
      お送りします（おすすめ）。
    ・ご自身で追加される場合は、「トップページ追加分.txt」の内容を、
      NISHI の欄の「</td></tr>」の次の行に貼り付けてください。

※ (1)(2) だけでも、次の URL を開いて「PDFを選択」から使えます。
   https://nextentertainmen.sakura.ne.jp/test/pdf_startlist.php
   https://nextentertainmen.sakura.ne.jp/test/pdf_result.php


■ 3. 使い方
--------------------------------------------------------------
トップページの「PDF」欄で PDF ファイルを選び、「GO!!」を押すと、
新しいタブに出力画面が開きます。

 【結果】
   1.php と同じ一覧表が表示されます。

 【スタートリスト　info-ch用 ソースコード】
   一番上の灰色の四角をクリックすると、表の HTML がまとめてコピーされます
   （NISHI 下段と同じです）。サイトにそのまま貼り付けてください。
   資格記録の位置（後ろ／前／表示しない）は、画面の「資格記録」で
   切り替えられます。切り替えると、すぐに表示とコピーの内容が変わります。

・PDF はブラウザの中だけで読み取り、サーバには送信・保存しません。
  7MB 程度の大きな PDF でも、サーバの設定変更は不要です。
・読み取りには、PDF の大きさにより数秒～15秒ほどかかります。
・PDF を読み取る部品（pdf.js）をインターネットから読み込むため、
  インターネットにつながっている必要があります。
・推奨ブラウザ：Google Chrome・Microsoft Edge


■ 4. スタートリストの出力内容
--------------------------------------------------------------
NISHI 下段（【info-ch用 ソースコード】）と同じ構成です
（種目ごとの開閉タブ＋表）。

 種目の見出し : 男子 100m 予選【成年】（性別・種目・ラウンド【種別】）
 組の行       : 「スタートリスト」（赤字）＋ ラウンド・組（例：予選 1組）
 各行         : 氏名(学年) 所属(都道府県) 資格記録

 ・ナンバー・レーンは表示せず、レーンの小さい順に並べています
   （レーンのない種目は、PDF の試技順・スタート順）。
 ・空いているレーンは詰めて表示します。
 ・リレーは「チーム名(都道府県)」の 1行です（メンバーは表示しません）。
 ・都道府県が書かれていない大会は、所属のみです。
 ・( ) の中の数字は PDF の表記のままです
   （学年。国スポのように生まれ年の下2桁の大会もあります）。
 ・出場者がまだ決まっていない組（準決勝・決勝の空欄など）は出力しません。

 色（ご指定の色）
   男子：組の行 #93C6F4 ／ 交互の行 #ECF5FF と白
   女子：組の行 #FFA4FD ／ 交互の行 #FFECFF と白
   ※ 男女混合の種目は、男子の色で表示します。


■ 5. 結果の出力内容
--------------------------------------------------------------
1.php（nishi.php）と同じ 16列・同じ表記で出力します。

 日付 / 大会名 / 種目 / 風速 / レース状況 / 組 / 順位 / 記録 / 氏名 /
 氏名カナ / 学年 / 所属1 / 所属2 / 性別 / 表示/非表示 / 備考

 ・種目    : 100M、4×100MR、走り高跳び、砲丸投げ など
 ・記録    : 1.50.87、6.85。400m 以下で 1分を超える記録は秒に換算します。
 ・風速    : トラックは組ごと、走幅跳・三段跳は各選手の記録の風です。
 ・リレー  : チーム名を所属1に出力します。
 ・混成競技 : 総合の記録のみ出力します。
 ・日付    : PDF のラウンドごとの日付。PDF にない場合は、上位8位一覧の日付。
 ・出力しないもの（1.php と同じ）
     混成競技の各種目、パラ種目、「タイムレース上位8位」などの一覧表


■ 6. 画面に表示されるお知らせ（「ご確認ください」）
--------------------------------------------------------------
 次の場合は、出力画面の上にお知らせを表示します。
 ・文字が図形・画像に変換されていて、読み取れないページがある場合
   （例：スタートリスト①の 6～26ページ）
   表紙・広告などのページであれば問題ありません。
 ・組の番号が飛んでいる場合（読み取れないページにある可能性があります）
 ・日付・大会名が見つからない場合
 ・印刷範囲の外にある見えない文字は、自動で読み飛ばします
   （例：スタートリスト①の 34ページ）。
