■ 2. 設置手順
--------------------------------------------------------------
(1) pdf_startlist.php・pdf_result.php・pdf_timetable.php を、サーバの test フォルダに
    アップロードしてください。

(2) pdf_js フォルダを、フォルダごと test フォルダにアップロードしてください。
    設置後は次のようになります。
      test/pdf_startlist.php
      test/pdf_result.php
      test/pdf_timetable.php
      test/pdf_js/pdfcore.js（ほか 7ファイル）

(3) tournament_result_top.php を test フォルダにアップロード（上書き）してください。
    お送りいただいたファイルの NISHI の欄の下に「PDF」欄を追加したものです。
    それ以外の部分は変更していません。
    ※ 作業前に、サーバの現在の tournament_result_top.php をバックアップしてください。

※ (1)(2) だけでも、次の URL を開いて「PDFを選択」から使えます。
   https://nextentertainmen.sakura.ne.jp/test/pdf_startlist.php
   https://nextentertainmen.sakura.ne.jp/test/pdf_result.php
   https://nextentertainmen.sakura.ne.jp/test/pdf_timetable.php


■ 3. 使い方
--------------------------------------------------------------
トップページの「PDF」欄で PDF ファイルを選び、「GO!!」を押すと、
新しいタブに出力画面が開きます。

 【結果】
   1.php と同じ一覧表が表示されます。

 【スタートリスト　info-ch用 ソースコード】
   一番上の灰色の四角をクリックすると、表の HTML がまとめてコピーされます
   （NISHI 下段と同じです）。サイトにそのまま貼り付けてください。
   資格記録の位置（後ろ／前／表示しない）は、画面の「資格記録」で
   切り替えられます。切り替えると、すぐに表示とコピーの内容が変わります。

 【タイムテーブル】
   競技日程・競技順序のページから、日付・時刻・性別・種別・種目・ラウンド・組の
   表を作ります（5-3 をご覧ください）。一番上の灰色の四角をクリックすると、
   表の HTML がまとめてコピーされます。
   プログラム（スタートリストと同じ PDF）の中の競技日程のページも読み取れます。

・PDF はブラウザの中だけで読み取り、サーバには送信・保存しません。
  7MB 程度の大きな PDF でも、サーバの設定変更は不要です。
・読み取りには、PDF の大きさにより数秒～15秒ほどかかります。
・PDF を読み取る部品（pdf.js）をインターネットから読み込むため、
  インターネットにつながっている必要があります。
・推奨ブラウザ：Google Chrome・Microsoft Edge

■ 4. スタートリストの出力内容
--------------------------------------------------------------
NISHI 下段（【info-ch用 ソースコード】）と同じ構成です
（種目ごとの開閉タブ＋表）。

 種目の見出し : 男子 100m 予選【成年】（性別・種目・ラウンド【種別】）
 組の行       : 「スタートリスト」（赤字）＋ ラウンド・組（例：予選 1組）
 各行         : 氏名(学年) 所属(都道府県) 資格記録

 ・ナンバー・レーンは表示せず、レーンの小さい順に並べています
   （レーンのない種目は、PDF の試技順・スタート順）。
 ・空いているレーンは詰めて表示します。
 ・リレーは「チーム名(都道府県)」の 1行です（メンバーは表示しません）。
 ・都道府県が書かれていない大会は、所属のみです。
 ・( ) の中の数字は PDF の表記のままです
   （学年。国スポのように生まれ年の下2桁の大会もあります）。
 ・出場者がまだ決まっていない組（準決勝・決勝の空欄など）は出力しません。

 色（ご指定の色）
   男子：組の行 #93C6F4 ／ 交互の行 #ECF5FF と白
   女子：組の行 #FFA4FD ／ 交互の行 #FFECFF と白
   ※ 男女混合の種目は、男子の色で表示します。

■ 5. 結果の出力内容
--------------------------------------------------------------
1.php（nishi.php）と同じ 16列・同じ表記で出力します。

 日付 / 大会名 / 種目 / 風速 / レース状況 / 組 / 順位 / 記録 / 氏名 /
 氏名カナ / 学年 / 所属1 / 所属2 / 性別 / 表示/非表示 / 備考

 ・種目    : 100M、4×100MR、走り高跳び、砲丸投げ など
 ・記録    : 1.50.87、6.85。400m 以下で 1分を超える記録は秒に換算します。
             「11.03[.026]」のような 1/1000 秒つきの記録は 1/100 秒（11.03）で出力します。
 ・風速    : トラックは組ごと、走幅跳・三段跳は各選手の記録の風です。
 ・レース状況 : 予選・決勝など。種別は【】で後ろに付けます
               （例：タイムレース決勝【1年】、予選【一般】）。
 ・リレー  : チーム名を所属1に出力します。
 ・混成競技 : 総合の記録のみ出力します。
 ・日付    : PDF のラウンドごとの日付。PDF にない場合は、上位8位一覧の日付。
             年が書かれていない PDF は、月日から年を判断します（お知らせを表示）。
 ・大会名  : PDF の大会名。書かれていない PDF は空欄で出力します（お知らせを表示）。
 ・組      : 「[Ａ決勝][B決勝]」のように分かれている決勝は、A決勝＝1組・B決勝＝2組
             として出力します。
 ・出力しないもの（1.php と同じ）
     混成競技の各種目、パラ種目、「タイムレース上位8位」などの一覧表


■ 5-2. 決勝一覧表（上位8位の一覧）だけの PDF
--------------------------------------------------------------
 詳しい結果の表がない PDF（「決勝一覧表」など、種目ごとに 1位～8位が並ぶ一覧）は、
 一覧の内容を上と同じ 16列で出力します。画面に「決勝一覧表から出力」と表示されます。
 ・レース状況 : 決勝【種別】（例：決勝【中学1年】、決勝【共通】）
 ・順位       : 一覧の 1位～8位（同順位で欄がまとまっている場合は、同じ順位で 2行）
 ・記録・風   : 「12.29/-0.9」は記録 12.29・風 -0.9。記録の下や種目名の下の風にも対応
 ・日付       : 一覧の日付。日付の欄がない一覧は、ページ上部の大会の日付
 ・大会名     : ページ上部の大会名（複数の大会が 1つの PDF に入っていても大会ごと）
 ・種別の欄が複数の種目にまたがっている表は、表の罫線から、どの種目の種別かを判断します。
 ※ 結果①・結果④のように、詳しい結果の表がある PDF では、上位8位の一覧は使いません
   （これまでどおり、詳しい結果の表から出力します）。


■ 5-3. タイムテーブルの出力内容
--------------------------------------------------------------
 日ごとに 1つの表にします。
   日付の行   : 9月27日（日）（背景 #6E6E6E・白い文字）
   項目名の行 : 時刻／性別／種別／種目／ラウンド／組
   種目の行   : #FFFFFF と #D0D6D4 を 1行ずつ交互（ご指定の色）
 ・種別（中学・高校・少年A・共通など）がない大会は、種別の列を出しません。
 ・招集時刻・参加数（人数）・ピットなどは出力しません。
 ・組
     時間帯が分かれている種目 … 時間帯ごとに 1行「1～15組」「16～27組」
     時間帯が 1つの種目       … 組の数「12組」（1組だけの種目は空欄）
     組ごとに行が分かれている表 … 「1組」「2組」
 ・ラウンドの「予」「準」「決」「タ決」「予7組3着＋3」などは、予選・準決勝・決勝・
   タイムレース決勝の表記にそろえます。「〃」は上の行と同じにします。
 ・混成競技の各種目は「八種競技 100m」のように表示します。
 ・並び順（画面で切り替え）
     時刻順（初期）… トラックとフィールドをまとめて、開始時刻の順
     PDFの順番     … PDF に書かれている順（トラック → フィールド）
 ・色・枠・太字は HTML に直接書いていますので、貼り付け先のサイトの CSS が
   効かない場合でも、そのまま表示されます。
 ・対応している表の作り
     見出しが 2～3段に分かれた表、左右に 2つ並んだ表（トラック／フィールド）、
     種目名や開始時刻のセルが複数の行にまたがっている表、招集の時間帯だけが
     分かれている表、日付が各ページの上にある複数日の大会


■ 6. 画面に表示されるお知らせ（「ご確認ください」）
--------------------------------------------------------------
 次の場合は、出力画面の上にお知らせを表示します。
 ・文字が図形・画像に変換されていて、読み取れないページがある場合
   （例：スタートリスト①の 6～26ページ）
   表紙・広告などのページであれば問題ありません。
 ・組の番号が飛んでいる場合（読み取れないページにある可能性があります）
 ・日付・大会名が見つからない場合
 ・PDF の中で文字の情報がない特殊な文字（外字）がある場合（「〓」で表示します）
 ・印刷範囲の外にある見えない文字は、自動で読み飛ばします
   （例：スタートリスト①の 34ページ）。
 ・タイムテーブル：開始時刻が読み取れなかった種目がある場合（空欄で出力し、種目名を表示）、
   競技日程の表が見つからない場合
